# SwiftMint Logo Concept

## Brand Identity

**SwiftMint** combines the concepts of **speed** (Swift) and **freshness/newness** (Mint), representing instant, modern financial transactions.

---

## Logo Concepts

### Concept 1: Lightning Bolt + Coin
**Description:**
- Primary element: Stylized lightning bolt
- Secondary element: Circular coin shape
- Represents: Speed + Money

**Visual:**
```
    ⚡
   ╱ ╲
  ╱   ╲
 ●─────●
  ╲   ╱
   ╲ ╱
    ○
```

**Colors:**
- Lightning: Electric blue (#0EA5E9)
- Coin: Gold gradient (#F59E0B → #FCD34D)
- Background: White or transparent

---

### Concept 2: S + Arrow
**Description:**
- Stylized letter "S" for Swift
- Arrow integrated into the S shape
- Represents: Direction, movement, progress

**Visual:**
```
  ╭───╮
  │ →─╯
  ╰─→ ╮
    ╰──╯
```

**Colors:**
- Primary: Vibrant blue (#0EA5E9)
- Accent: Teal (#14B8A6)
- Gradient option: Blue to purple

---

### Concept 3: Abstract Mint Leaf + Movement Lines
**Description:**
- Simplified mint leaf icon
- Motion lines suggesting speed
- Represents: Fresh start + Velocity

**Visual:**
```
    🍃
   ╱│╲
  ╱ │ ╲ ≡≡≡
 ╱  │  ╲
    │
```

**Colors:**
- Leaf: Fresh mint green (#10B981)
- Lines: Light blue (#38BDF8)
- Background: White

---

### Concept 4: Circular Orbit (Recommended)
**Description:**
- Central circle representing global
- Orbital ring suggesting movement
- Modern, tech-forward aesthetic

**Visual:**
```
    ╱───╲
   ╱  ●  ╲
  │   ○   │
   ╲  ●  ╱
    ╲───╱
```

**Colors:**
- Center: Solid primary blue (#0EA5E9)
- Orbit: Gradient (blue to purple)
- Dots: Accent colors

## Typography

### Primary Font: **Inter** (Sans-serif)
- Modern, clean, highly readable
- Excellent for digital displays
- Variable font for flexibility

**Logo Text:**
```
SwiftMint
```

**Weight:** Bold (700)
**Letter Spacing:** -0.02em (tight)
**Case:** Mixed case (recommended) or Title Case

### Secondary Font: **Space Grotesk**
- Geometric, modern
- Good for headings
- Pairs well with Inter

## Logo Usage Guidelines

### Minimum Size
- **Digital:** 120px width
- **Print:** 1 inch width
- **App Icon:** 512x512px

### Clear Space
- Maintain clear space equal to height of "S" in SwiftMint
- No elements should intrude into this space

### Incorrect Usage
❌ Don't stretch or distort
❌ Don't change colors arbitrarily
❌ Don't add effects (drop shadow, glow)
❌ Don't rotate
❌ Don't place on busy backgrounds

### Correct Usage
✅ Use approved color variations
✅ Maintain aspect ratio
✅ Use on solid backgrounds
✅ Ensure sufficient contrast
✅ Use vector formats when possible
