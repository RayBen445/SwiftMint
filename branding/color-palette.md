# SwiftMint Color Palette

## Primary Colors

### Brand Blue
- **Primary 600**: `#0284c7` - Main brand color, CTA buttons
- **Primary 700**: `#0369a1` - Hover states, emphasis
- **Primary 500**: `#0ea5e9` - Lighter accent, highlights
- **Primary 400**: `#38bdf8` - Very light, backgrounds

**Usage**: Primary actions, navigation, key UI elements, links

**Psychology**: Trust, reliability, professionalism, technology

### Accent Colors

#### Success Green
- **Success 600**: `#16a34a`
- **Success 500**: `#22c55e`
- **Success 100**: `#dcfce7`

**Usage**: Completed transactions, success messages, positive indicators

#### Warning Orange
- **Warning 600**: `#ea580c`
- **Warning 500**: `#f97316`
- **Warning 100**: `#ffedd5`

**Usage**: Pending transactions, alerts, important notices

#### Error Red
- **Error 600**: `#dc2626`
- **Error 500**: `#ef4444`
- **Error 100**: `#fee2e2`

**Usage**: Failed transactions, errors, critical alerts

## Accessibility

All color combinations meet WCAG 2.1 AA standards:
- Primary 600 on white: 4.5:1 contrast ratio
- Gray 900 on white: 18:1 contrast ratio
- White on Primary 600: 4.5:1 contrast ratio

## Color Usage Guidelines

1. **Maintain Consistency**: Use the same color for similar actions across the app
2. **Hierarchy**: Use darker colors for more important elements
3. **Accessibility**: Always check contrast ratios for text
4. **State Changes**: Use opacity or darker shades for hover/active states
5. **Cultural Considerations**: Blue is universally trusted for financial apps
